# PokéTimes

Front-end do projeto final. A interface consome a [PokéAPI](https://pokeapi.co/). Os times ficam salvos no navegador até a fase de back-end.

## Scripts

```bash
npm install
npm run dev
```

Abra `http://localhost:5173`.

- `/` página inicial, com busca
- `/pokedex` lista vinda da API
- `/pokemon/:name` ficha do Pokémon
- `/times` times criados neste navegador
- `/sobre` informações do autor
